AI HR Assistant

A Telegram bot that answers employees' HR questions from the company's own documents, in the language they write in. This page simulates a chat with sample policies, so you can see how it behaves without Telegram.

Ask a question

    What happens behind the scenes

    1. 1Finds the right passages. HR policies (PDF, Word, text) are split into chunks and searched by meaning, not by exact words.
    2. 2Answers only from them. The language model writes the reply using those passages only and links the source document.
    3. 3Admits what it doesn't know. If the documents have no answer, it sends the person to HR instead of guessing, and logs the question.
    4. 4Reports to HR monthly. Unanswered questions show HR exactly which policies are missing.
