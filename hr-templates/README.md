# Recruitment templates

Templates I built to make hiring more structured, so that decisions rest on agreed criteria and scores rather than on impressions. **Preview them in the browser:** https://sviatoslav43.github.io/hr-templates/

Built in Google Sheets; to use them, open a file in Google Sheets (File → Import) so that the formulas keep working.

| Template | What it is for |
|---|---|
| [Vacancy brief](Vacancy_Brief_template.xlsx) | Filled in with the hiring manager at the kick-off meeting: requirements, salary range, hiring stages and what the new hire must achieve during probation. |
| [Interview scorecard](Interview_Scorecard_Sales_template.xlsx) | Example for a sales role: weighted criteria scored 1–4, red flags, a scoring guide for interviewers and a final recommendation. |
| [Candidate comparison tracker](Candidate_Comparison_Tracker_template.xlsx) | Pulls scores from each candidate's scorecard (via IMPORTRANGE) into one side-by-side view, plus a decision log. |
| [Hiring roadmap](Hiring_Roadmap_template.xlsx) | Step-by-step plan for a vacancy: who does what, sourcing channels and search strings. |
| [Recruitment process (SOP)](Recruitment_Process_SOP.xlsx) | The end-to-end process from vacancy approval to closing, in Ukrainian and English. |
| [Vacancy analytics](Vacancy_Analytics_template.xlsx) | Time to hire and fill, stage-to-stage conversion, source effectiveness and rejection reasons. |

All names and data in the templates are examples.
